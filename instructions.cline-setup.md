## <div align="center"> Cline Setup </div>

1. Clone the repository into your local machine.
2. Open repository via Cline
3. Paste the following prompt to the Cline agent:

```txt
I need you to install this github-copilot plugin that is located inside plugin/wagents, install it globally for yourself, so YOU(Cline) can use it. Make sure you adjust format of agents, mcps, etc. so it is in your native format.
```
