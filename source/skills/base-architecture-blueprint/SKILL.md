# Architecture Blueprint (wagents original)

## When to use
- New systems, major refactors, technology selection, legacy modernization.

## Workflow
1. Inspect current project and constraints.
2. Define components, boundaries, data flows.
3. Evaluate options with tradeoffs.
4. Use current docs for framework decisions.
5. Record significant decisions as ADRs.
6. Distinguish facts from assumptions.

## Rules
- No implementation unless requested.
- Prefer simple maintainable designs.
- Document deviations.
