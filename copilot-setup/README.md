## <div align="center"> Github-Copilot Setup </div>

1. Clone the repository into your local machine.
2. Open copilot-setup folder
3. Copy contents of .copilot folder into your %USERROOT%/.copilot folder
4. Copy contents of AppData-Code-User folder into your %USERROOT%/AppData/Code/User/ folder
